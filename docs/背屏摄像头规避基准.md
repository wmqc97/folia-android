# 背屏摄像头规避区域（确认基准）

> 真机实测确认（小米 17 Pro Max / 2509FPN0BC / popsicle）。
> 一切背屏渲染适配以本文件为准，不要凭感觉改。

## 单位换算

背屏物理分辨率 **976×596**，系统 density **450dpi**（base 160）。

```
dpr = 450 / 160 = 2.8125
CSS = 物理 / 2.8125
物理 = CSS × 2.8125
```

## 区域划分

| 区域 | 物理 px | CSS px | 说明 |
|---|---|---|---|
| **摄像头占用（红）** | 0 .. 277 | **0 .. 98** | 左侧竖带，物理挖孔，内容不要画进来 |
| **可读区（绿）** | 277 .. 976 | **98 .. 347** | 歌词只能放这里 |
| 可读区宽度 | 699 | **249** | |
| **可读区中心 X** | **626.5** | **222.5** | 歌词焦点目标位置 |
| 可读区半宽 | 349.5 | **124.5** | |

屏幕高度 596 物理 / 212 CSS，纵向全高可用。

## 允许摆动

- 摆幅 **±22.5 CSS / ±63 物理**（绝对上限，可调小）；
- 摆动范围 **200 .. 245 CSS / 562 .. 689 物理**；
- **绝不允许** X < 98 CSS 或 X > 347 CSS。

## 视觉约定

- **红色斜纹** = 摄像头占用；
- **绿色斜纹** = 可读区；
- **黄色竖线** = 目标焦点中心 222.5 CSS；
- **橙色虚线** = 摆动边界 ±22.5 CSS。

## 镜台样式适配原则（用户确认）

1. **效果撤回到主屏一样**：3D 运镜、粒子、雾气、装饰全部保持原样，**不改运镜**；
2. **只做歌词可读性适配**：把当前行 + 邻行的**焦点中心**从屏幕中心（173.5）右移到 **222.5 CSS**；
3. **轻微摆动**：允许在右侧区域内小幅游走，但绝不出绿区；
4. **不修改歌词显示范围 / 画布尺寸 / 字号 / 效果缩放**，只改**渲染位置**；
5. **背景/粒子/相机不动**，只平移歌词组的世界坐标。

## 渲染面坐标系

背屏渲染面 587×452（overscan 120）：

- 渲染面原点相对屏幕 = `(-120, -120)`；
- 取景窗中心 X（屏幕）= `173.5 + canvasX + centerOffsetX`；
- 要让焦点落在 222.5 CSS：
  - `canvasX = 0` 时，`centerOffsetX = 222.5 - 173.5 = **49**`
  - 或者保持 `centerOffsetX = 0`，在 3D 里把歌词组投影夹到 `222.5`。

## 陷阱

1. `WebViewAssetLoader` 加载时 query 可能被吃掉，**用 `window.__FOLIA_REAR__` 全局标记 + URL query 双重判定**；
2. `android.os.SystemProperties` 是 `@hide` API，**反射调用**；
3. `CameraRig` 的 `resolveShotOffset` / `resolveCameraDrift` / `resolveReadHeadTruck` / `lookR` 是 5 层运动源，**不改运镜时必须保留**，只把歌词组夹到安全区；
4. `DioramaScene` 的 `unitsGroup` 是当前行，**只夹它，不动相机、邻行、背景**；
5. 换算 `NDC → 世界`：`tan(fov/2) × aspect × |view.z|`，`view.z` 来自 `camera.matrixWorldInverse`；
6. 相机右向量用 `setFromMatrixColumn(camera.matrixWorld, 0)`，不要用 `frame.right`。
