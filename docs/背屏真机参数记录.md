### 3.1 关于「两个孔」

系统把左侧两个摄像头**合并上报为一条 cutout**：

```
cutout DisplayCutout{insets=Rect(296, 0 - 0, 0)
  boundingRect={Bounds=[Rect(0, 0 - 296, 596), Rect(0,0-0,0), ...]}
  cutoutSpec={M -488,0 L -488,596 L -192,596 L -192,0 Z @bind_left_cutout}}
```

`cutoutSpec` 的 x 范围 -488 → -192（相对屏幕中心），换算成屏幕坐标即 **0 → 296**，高度 596（全高）。

**结论：不需要区分两个孔。系统 cutout 报 296 px，其中摄像头玻璃的硬边缘在 277 px；
本项目歌词画布跟硬件 277（换算 CSS 98），296 只作为系统兜底。**

### 3.2 CSS 像素换算（背屏 WebView 用）

背屏 density 450 → 缩放系数 `450 / 160 = 2.8125`：

| 量 | 原生 px | CSS px |
|---|---|---|
| 背屏视口宽 | 976 | **347.0** |
| 背屏视口高 | 596 | **211.9** |
| 系统 cutout 宽 | 296 | **105.2** |
| 摄像头硬边缘 | 277 | **98.5** |
| 内容区宽（按 277） | 699 | **248.5** |
| 圆角半径 | 101 | **35.9** |

> 注意：背屏 CSS 视口只有约 **347 × 212 px**，非常小。字号、间距、控制面板都要按这个尺寸设计，不能沿用主屏的尺寸。

### 3.3 圆角与 MiRoot 常量对照

| 项 | MiRoot 常量 | 本机实测 | 说明 |
|---|---|---|---|
| 背屏圆角 | 35 dp | 101 px ÷ 2.8125 = **35.9 dp** | ✅ 与 MiRoot 的 35dp 一致 |
| 左侧安全区 | 277 px | **296 px（系统）/ 277 px（硬件）** | ✅ MiRoot 的 277 是玻璃硬边缘；本项目歌词画布用 277，296 只作系统兜底 |

## 5. 对方案的影响

1. **安全带宽度确定 = 296 px（≈105.2 CSS px）**，不再是 MiRoot 的 277px 估算值。§3.4 的「固定宽度」直接用这个数。
2. **双孔不需要特殊处理**：系统已合并成一条左侧 cutout，取 `insets.left` 即可。
3. **背屏视口极小（347×212 CSS px）**：背屏 UI 必须单独按这个尺寸设计，不能复用主屏尺寸。
4. **权限方案确认为「Shizuku 单通道」**：本机无 root，root 增强在本机不适用（但代码里保留 root 优先分支，便于其他设备）。
5. **REAREye 已安装**：锁屏直启有优化空间，阶段 4 可以接入检测。
6. **18 Pro 系列仍无数据**：需要用户提供该机型后重复本节流程。

## 7. 前端用到的 CSS 常量（与本节实测值的对应）

背屏 WebView 里实际参与布局的就三个数，全部由本节的原生实测值推出来：

| 常量 | 值 | 来源 |
|---|---|---|
| 背屏 CSS 视口 | **347 × 212** | 976 × 596 ÷ 2.8125（density 450 / 160） |
| 左侧安全带 CSS 宽 | **105** | 296 ÷ 2.8125，代码常量 `DEFAULT_REAR_SAFE_LEFT_CSS` |
| 可见区 CSS 宽 | **242** | 347 − 105 |

安全带宽度**不在前端硬编码**：`resolveRearSafeLeftCss()`（`src/services/rearLyricsBridge.ts`）
优先用原生经 URL 传进来的 `safeLeftPx` / `physicalWidthPx` 算比值
（`safeLeftPx × CSS视口宽 ÷ 屏幕物理宽`），取不到再退 `devicePixelRatio`，最后才用 105 兜底。
原因：背屏 WebView 的视口缩放不一定是标准 dpr，直接用 dpr 换算会偏。
所以**换机型只要原生侧读到新的 `insets.left`，前端不用改**。

本地探针复现时手动带上这两个参数即可：

```
http://127.0.0.1:4173/dev-probe.html?probe=rearLyrics&safeLeftPx=296&physicalWidthPx=976
```
